## 소개

**엘리엇 파동 분석**은 주식 시장의 가격 움직임이 특정한 패턴(5-3 파동)으로 반복된다는 이론에 기반한 기술적 분석 도구입니다.

### 주요 기능
- ✅ ZigZag 알고리즘으로 주요 전환점 자동 감지
- ✅ 5파 충격파(1-2-3-4-5) 자동 인식
- ✅ 3파 조정파(A-B-C) 자동 인식
- ✅ 피보나치 비율 검증
- ✅ 엘리엇 파동 규칙 준수 여부 확인
- ✅ 신뢰도 점수 계산 (0-100%)
- ✅ 다음 목표가 예측
- ✅ 시각화 차트 생성

## 고급 옵션

### Shell 스크립트 옵션

| 옵션 | 설명 | 기본값 | 예시 |
|------|------|--------|------|
| `-e, --elliott` | 엘리엇 파동 분석 활성화 | false | `--elliott` |
| `--elliott-min-wave` | 최소 파동 크기 (%) | 3.0 | `--elliott-min-wave 5.0` |
| `--elliott-zigzag` | ZigZag 임계값 (%) | 5.0 | `--elliott-zigzag 7.0` |
| `--adjusted` | 조정 가격 사용 | false | `--adjusted` |

### Python 스크립트 옵션

```bash
python test/elliott_wave_test.py [TICKER] [PERIOD] [OPTIONS]

Options:
  --from DATE              시작 날짜 (YYYY-MM-DD)
  --to DATE                종료 날짜 (YYYY-MM-DD)
  --min-wave-size FLOAT    최소 파동 크기 (%, 기본값: 3.0)
  --zigzag-threshold FLOAT ZigZag 임계값 (%, 기본값: 5.0)
  --no-chart               차트 생성 안함 (분석만)
  --auto_adjust true/false 가격 조정 여부 (기본값: false)
```

### 매개변수 설명

#### `min-wave-size` (최소 파동 크기)
- 작은 노이즈를 필터링하는 임계값
- **값이 클수록**: 큰 파동만 감지 (노이즈 감소, 파동 수 감소)
- **값이 작을수록**: 작은 파동까지 감지 (상세 분석, 노이즈 증가)
- **권장값**:
  - 변동성 높은 종목: 5.0 ~ 7.0
  - 안정적인 종목: 2.0 ~ 4.0
  - 기본값: 3.0

#### `zigzag-threshold` (ZigZag 임계값)
- 전환점 감지 민감도
- **값이 클수록**: 큰 전환점만 감지 (단순화)
- **값이 작을수록**: 작은 전환점도 감지 (상세)
- **권장값**:
  - 장기 분석 (6개월 이상): 7.0 ~ 10.0
  - 중기 분석 (3-6개월): 5.0 ~ 7.0
  - 단기 분석 (3개월 미만): 3.0 ~ 5.0
  - 기본값: 5.0

### 신뢰도 점수 해석

| 점수 | 의미 | 추천 행동 |
|------|------|-----------|
| 70-100% | 높은 신뢰도 | 패턴이 명확. 엘리엇 파동 기반 전략 적용 가능 |
| 50-69% | 중간 신뢰도 | 패턴이 감지되나 추가 검증 필요 |
| 0-49% | 낮은 신뢰도 | 패턴 불명확. 다른 지표와 함께 확인 |

### 파동 위치별 전략

#### 파동 3 진행 중 ✅
- **가장 강력한 파동**
- 거래량 급증, 추세 확실
- **전략**: 보유 유지, 추가 매수 고려

#### 파동 4 진행 중 ⚠️
- 조정 구간
- 피보나치 38.2%-50% 되돌림 예상
- **전략**: 추가 매수 기회 (마지막 진입)

#### 파동 5 진행 중 ⚠️
- 마지막 상승파
- 거래량 감소 주의
- **전략**: 이익 실현 준비, 스톱로스 설정

#### 파동 5 종료 후 ⛔
- 조정파(A-B-C) 시작 예상
- **전략**: 매도 또는 헤지, 조정 후 재진입 계획

#### 조정파(A-B-C) 진행 중 📉
- 되돌림 구간
- 피보나치 지지선에서 반등 가능
- **전략**: 지지선 근처에서 분할 매수

## 문제 해결

### 문제 1: "충분한 피봇 포인트가 없습니다"

**원인**:
- 데이터 기간이 너무 짧음
- ZigZag 임계값이 너무 높음

**해결책**:
```bash
# 기간 늘리기
./hma.sh -s AAPL -p 1y --elliott

# ZigZag 임계값 낮추기
./hma.sh -s AAPL -p 120d --elliott --elliott-zigzag 3.0
```

### 문제 2: "엘리엇 파동 패턴을 찾을 수 없습니다"

**원인**:
- 명확한 파동 패턴이 없음 (횡보장)
- 파라미터가 부적절

**해결책**:
```bash
# 최소 파동 크기 조정
./hma.sh -s AAPL -p 120d --elliott --elliott-min-wave 2.0

# 다른 기간 시도
./hma.sh -s AAPL -p 6mo --elliott
```

### 문제 3: 신뢰도가 낮음 (<50%)

**원인**:
- 파동이 엘리엇 규칙을 잘 따르지 않음
- 복잡한 조정 패턴

**해결책**:
- 다른 기술적 지표와 함께 사용
- 더 긴 기간으로 분석
- HMA, RSI, Volume Profile과 결합

```bash
# Volume Profile과 함께 사용
./hma.sh -s AAPL -p 6mo -v overlay --elliott
```

### 문제 4: 너무 많은 파동이 감지됨

**원인**:
- 파라미터가 너무 민감

**해결책**:
```bash
# 최소 파동 크기와 ZigZag 임계값 증가
./hma.sh -s AAPL -p 120d --elliott \
  --elliott-min-wave 5.0 \
  --elliott-zigzag 7.0
```

### 문제 5: 차트가 복잡하고 보기 어려움

**원인**:
- 피봇 포인트가 너무 많음

**해결책**:
```bash
# 큰 파동만 보기
./hma.sh -s AAPL -p 1y --elliott \
  --elliott-min-wave 7.0 \
  --elliott-zigzag 10.0
```

## 다른 지표와의 결합

### 1. HMA + 엘리엇 파동

```bash
# Volume Profile Overlay + 엘리엇 파동
./hma.sh -s AAPL -p 6mo -v overlay --elliott
```

**시너지 효과**:
- HMA 상승 전환 + 엘리엇 파동 3 → 강력한 매수 신호
- HMA 하락 전환 + 엘리엇 파동 5 종료 → 강력한 매도 신호

### 2. Volume Profile + 엘리엇 파동

**분석 포인트**:
- POC(Point of Control)가 파동 전환점과 일치
- High Volume Node가 피보나치 레벨과 일치

### 3. 투자 전략 분석 + 엘리엇 파동

```bash
./hma.sh -s AAPL -p 6mo -a strategy -v overlay --elliott
```

**종합 분석**:
- HMA/VST 신호
- Volume Profile
- 엘리엇 파동 위치
- RSI, MACD 등 기술적 지표

## 모범 사례 (Best Practices)

### ✅ DO

1. **여러 시간 프레임 확인**
   ```bash
   # 장기 (큰 그림)
   ./hma.sh -s AAPL -p 1y --elliott --elliott-zigzag 10.0
   
   # 중기 (전술적)
   ./hma.sh -s AAPL -p 6mo --elliott --elliott-zigzag 5.0
   
   # 단기 (진입 타이밍)
   ./hma.sh -s AAPL -p 90d --elliott --elliott-zigzag 3.0
   ```

2. **다른 지표와 함께 사용**
   - RSI 다이버전스 확인
   - MACD 크로스오버
   - Volume Profile 지지/저항

3. **신뢰도 점수 참고**
   - 70% 이상: 높은 가중치
   - 50-69%: 보조 지표로 활용
   - 50% 미만: 참고만

4. **피보나치 레벨 활용**
   - 조정 시 38.2%, 50%, 61.8% 근처에서 매수
   - 목표가로 161.8%, 200% 설정

### ❌ DON'T

1. **엘리엇 파동만 맹신하지 말 것**
   - 주관적 해석 여지가 큼
   - 다른 분석과 결합 필수

2. **복잡한 조정 패턴 강제 해석 금지**
   - 명확하지 않으면 다른 도구 사용

3. **낮은 신뢰도 패턴으로 거래하지 말 것**
   - 신뢰도 50% 미만은 무시

4. **단기 노이즈에 휘둘리지 말 것**
   - 큰 그림 보기
   - 장기 추세 우선
