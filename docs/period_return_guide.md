# 검색기간 수익률 가이드

## 개요
검색기간 수익률은 분석 시작일부터 종료일까지의 주가 변화를 나타내는 지표로, 실시간가/현재가 이전에 출력되어 투자자에게 중요한 기간별 성과 정보를 제공합니다.

## 📊 계산 공식

### 기본 수익률 계산
```
수익률(%) = ((종료가 - 시작가) / 시작가) × 100
수익금액($) = 종료가 - 시작가
```

### 예시
- **시작가**: $100.00 (2024-01-01)
- **종료가**: $120.00 (2025-08-22)
- **수익률**: ((120 - 100) / 100) × 100 = 20.00%
- **수익금액**: 120 - 100 = $20.00

## 🎯 표시 정보

### 1. 기본 정보
- **검색기간**: 시작일 → 종료일
- **시작가**: 분석 시작일의 종가
- **종료가**: 분석 종료일의 종가
- **수익률**: 퍼센트 단위의 변화율
- **수익금액**: 달러 단위의 절대 변화량

### 2. 방향 표시
- **▲ 상승**: 양의 수익률 (초록색)
- **▼ 하락**: 음의 수익률 (빨간색)  
- **→ 보합**: 0% 변화 (회색)
