# Thin 스타일 라인 가이드

## 개요
차트의 수직선과 수평선의 두께를 모두 thin 스타일로 조절하여 캔들바와 다른 차트 요소들이 더 잘 보이도록 개선했습니다.

## Thin 스타일의 장점

### 1. 가독성 향상
- 캔들바와 겹쳐도 캔들바가 잘 보임
- 다른 차트 요소들과의 겹침 최소화

### 2. 시각적 일관성
- 모든 라인이 동일한 thin 스타일로 통일
- 차트 전체의 깔끔한 느낌

### 3. 정보 전달력 향상
- 중요한 가격 정보가 가려지지 않음
- 차트 분석 시 더 정확한 판단 가능

## 라인 두께 기준

### Thin 스타일 (0.2 ~ 0.5)
- **0.2**: 가장 얇은 라인 (낮은 거래량 수평선)
- **0.3**: 기본 thin 라인 (대부분의 수평선, RSI, MACD)
- **0.4**: 중간 thin 라인 (높은 거래량 수평선)
- **0.5**: POC 등 중요한 지지/저항선

### 기존 대비 감소율
- **수평선**: 평균 50~75% 감소
- **POC 라인**: 50% 감소
- **거래량 기반 라인**: 50~75% 감소

## 적용된 차트 유형

1. **메인 차트**: 현재가, 지지선, 저항선
2. **RSI 차트**: 30, 50, 70 기준선
3. **MACD 차트**: 0 기준선
4. **VIX 차트**: 박스권 경계선
5. **Volume Profile**: POC, Value Area
6. **거래량 기반**: 종가 기준 수평선

## 사용 예시

```python
# 기존 코드 (두꺼운 라인)
ax_main.axhline(y=current_price, color='black', linestyle=':', linewidth=0.8, alpha=0.5)

# 수정된 코드 (thin 스타일)
ax_main.axhline(y=current_price, color='black', linestyle=':', linewidth=0.3, alpha=0.5)
```

## 주의사항

1. **라인 너무 얇아짐**: 0.2 이하로 설정하면 인쇄 시 보이지 않을 수 있음
2. **투명도 조정**: `alpha` 값을 적절히 조정하여 가시성 확보
3. **zorder 설정**: 라인 간 겹침 순서를 적절히 조정

## 향후 개선 방향

1. **사용자 설정 옵션**: thin/medium/thick 스타일 선택 가능
2. **동적 두께 조절**: 화면 크기에 따른 자동 조절
3. **테마별 스타일**: 다크/라이트 테마에 따른 최적화
