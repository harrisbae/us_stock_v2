# CME FedWatch Tool 수동 확인 가이드

## 개요

CME FedWatch Tool은 연방기금금리 선물 계약을 기반으로 시장의 금리 정책 기대를 보여주는 중요한 지표입니다. 자동화된 스크래핑이 차단되어 있어 수동으로 확인하는 방법을 안내합니다.

## 직접 접속 방법

### 1. 웹사이트 접속
**URL**: https://www.cmegroup.com/markets/interest-rates/cme-fedwatch-tool.html

### 2. 주요 섹션 확인

#### Target Rate Probabilities (목표금리 확률)
- **위치**: 페이지 중앙 상단
- **내용**: 각 FOMC 회의별 금리 수준별 확률
- **표시 형태**: 
  - Meeting Date (회의일)
  - Target Rate (목표금리)
  - Probability (확률)

#### Current Rate (현재 금리)
- **위치**: 페이지 상단
- **내용**: 현재 연방기금금리 수준
- **예시**: 4.50% (2025년 8월 기준)

#### Rate Change Probabilities (금리 변화 확률)
- **위치**: Target Rate Probabilities 아래
- **내용**: 현재 금리 대비 변화 확률
- **표시 형태**:
  - Rate Cut (금리인하)
  - No Change (변화 없음)
  - Rate Hike (금리인상)

## 데이터 해석 방법

### 1. 금리 수준별 확률 확인
```
예시: 2025-09-17 FOMC
- 4.25%: 15.2% (25bp 인하 확률)
- 4.50%: 45.8% (현행 유지 확률)
- 4.75%: 39.0% (25bp 인상 확률)
```

### 2. 금리 방향성 분석
- **현재 금리**: 4.50%
- **금리인하 확률**: 4.25% (15.2%) + 4.00% (0%) = 15.2%
- **현행 유지 확률**: 4.50% (45.8%)
- **금리인상 확률**: 4.75% (39.0%)

### 3. 시장 심리 판단
- **15.2% < 50%**: 금리인하 기대 낮음
- **45.8% > 39.0%**: 현행 유지 기대 우세
- **전체적 판단**: 현행 금리 유지 기대

## 투자 시사점

### 1. 금리인하 기대가 높을 때 (50% 이상)
- **주식시장**: 긍정적 (성장주 선호)
- **채권시장**: 긍정적 (채권가격 상승)
- **섹터**: 기술주, 금융주, 소비자 경기 민감주

### 2. 현행 유지 기대가 높을 때
- **주식시장**: 중립적 (현재 추세 유지)
- **채권시장**: 중립적 (현재 수준 유지)
- **섹터**: 배당성장주, 품질주, 균형잡힌 포트폴리오

### 3. 금리인상 기대가 높을 때 (50% 이상)
- **주식시장**: 부정적 (성장주 압박)
- **채권시장**: 부정적 (채권가격 하락)
- **섹터**: 방어주, 고배당주, 현금 보유
